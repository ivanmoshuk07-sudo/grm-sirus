# GRM Sirus Check

Диагностический аддон для проверки состава гильдии на Sirus 3.3.5a+.

1. Скопируйте папку `GRMSirusCheck` в `Interface/AddOns`.
2. Войдите в игру персонажем в гильдии и выполните `/grmsirus 5`.

Команда выводит имя, ранг, онлайн-статус и заметки первых пяти участников. Офицерские заметки видны при наличии права просмотра. Команда принимает число от 1 до 50.

Это первый шаг к оценке совместимости GRM с Sirus. Логика проверена на имитации API. Запуск в клиенте Sirus пока не проверен.
