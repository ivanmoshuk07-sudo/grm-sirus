# GRM Sirus Check

Диагностический аддон для проверки состава гильдии на Sirus 3.3.5a+.

1. Скачайте `GRMSirusCheck.zip` из [раздела Releases](https://github.com/ivanmoshuk07-sudo/grm-sirus/releases).
2. Распакуйте ZIP в `Interface/AddOns`. Файл аддона должен оказаться по пути `Interface/AddOns/GRMSirusCheck/GRMSirusCheck.toc`.
3. Войдите в игру персонажем в гильдии и выполните `/grmsirus 5`.

Команда выводит имя, ранг, онлайн-статус и заметки первых пяти участников. Офицерские заметки видны при наличии права просмотра. Команда принимает число от 1 до 50. Если состав уже доступен в кэше клиента, аддон покажет его сразу.

Это первый шаг к оценке совместимости GRM с Sirus. Логика проверена в Lua 5.1 на имитации API WoW 3.3.5a. Запуск в клиенте Sirus пока не проверен.
